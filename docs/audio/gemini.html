Audio with Gemini

Gemini is built for music. The sound effects in Step 4 are an experiment. If they come out badly, the game keeps its built-in sounds.

Step 1: Open Create music

  1. Open gemini.google.com or the Gemini app.
  2. Switch the model to Pro (needed for full-length songs).
  3. Tap Upload & tools → Create music.
  4. For songs, set Vocals: off and Length: full.

Step 2: One song per prompt

Tap Copy, paste into Gemini, wait. Then Download → audio only (MP3) and rename the file to the name shown.

Don't like it? Run the same prompt again: each try sounds different.

Step 4 (experiment): sound effect reels

Gemini can't make one tiny sound per file. So each prompt asks for a reel: several sounds in a fixed order, with silence between them. I cut the reel at the silent gaps and name each sound by its place in the order.

  • Set Length: short.
  • Vocals: as shown on each card (voices need vocals on).
  • Rename each download as shown, e.g. reel1-hits.mp3.
  • Listen once. If it became a song or the order is wrong, run it again.

Good to know

  • When a song restarts, you may hear a small jump. That's normal for generated music.
  • Every Gemini track has an invisible AI watermark. It doesn't change the sound.
  • Don't name real artists or games in a prompt: Gemini blocks those.
  • Any sound that comes out badly stays on the built-in version.
